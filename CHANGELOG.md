# 更新日志 / Changelog

## 0.1.0-beta.1

### 中文

- 在 DSH 侧栏集中查阅原生计划的投递、执行和报告验收状态。
- 通过回执消息 ID 关联计划运行与会话轮次。其他任务写入同一路径时，显示文件发生变化和归属不足。
- 支持日期路径模板和必需 Markdown 标题，保留验收时的文件版本、人工确认和已读状态。

### English

- Review delivery, execution, and report results for native schedules from the DSH sidebar.
- Match each run to its session turn using the delivery message ID. Changes from another task remain unattributed.
- Set date-based paths and required Markdown headings. Keep the reviewed file version, manual confirmation, and read state.
